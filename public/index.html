    Current session
    Automatic queue

    Off by default. When enabled, pause after every expected attempt: finish, quit, or failure. Resume continues to the next entry, not a replay. Changes apply to attempts starting after the save.

    Console event observations

    Queue storage failure

    Restore database/filesystem availability, then reconcile retained results and gameplay boundaries without sending console requests again. Recovery leaves the queue paused; a new song-selection observation and explicit Resume are required. Unresolved console requests remain quarantined.

    Unresolved transmitted console request

    Only if its response cannot resolve the request: actually restart the game/console first. This confirmation does not restart it remotely. It clears only the displayed request, resets observations and leaves the queue paused. A new song-selection observation and explicit Resume are required.
